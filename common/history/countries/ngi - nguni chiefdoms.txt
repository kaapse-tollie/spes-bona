# Nguni Chiefdoms (NGI) - decentralized abstraction for the remnant southern-Natal
# Nguni groups under Nhlangwini leadership after the collapse of the Thuli paramountcy.
# Historically the regional network (Nhlangwini under Fodo kaNombewu, then successors)
# paid tribute up to Dingane. The linked budget modifiers are history-authored so
# the payment is visible at game start, then maintained by the monthly pulse. The tag keeps the
# south Natal strip from starting as a clean Zulu/Boer possession and gives the Retief
# chain a plausible frontier (Wright, in Laband & Haswell eds. 1988, pp. 18-21).
COUNTRIES = {
	c:NGI ?= {
		effect_starting_technology_tier_6_tech = yes
		effect_starting_politics_traditional = yes
		activate_law = law_type:law_debt_slavery
		add_modifier = { name = sb_tribute_to_zul }
	}
}
