## D1 — recommended baseline

Use the immutable **1.67.0 release**, then derive only the compatibility delta
still required by SB. Staging should first review the old patch contracts and
SB's own replacements, then validate the resulting dependency/SB combination
before any later installation. Do not apply `sb-1.14.3-r1` wholesale to this base.

Continuing to port 1.66 would duplicate the upstream journal, presentation and
political work and leave SB maintaining a larger divergence. Waiting for another
release remains an option if a blocking issue is discovered, but the two old
trigger calls and seven ideology references found here do not by themselves
justify rejecting 1.67 as the starting point. Their corrections are still
proposed, not engine-verified fixes.

## D2 — recommended territorial-hook treatment

The [released hook definition](https://github.com/Victoria-3-Modding-Co-op/Community-Mod-Framework/blob/9ca5ff4df2723744e2c6c4470ca955eaccd2724c/common/scripted_triggers/00_tlim_triggers.txt)
is `hidden_trigger = { always = yes }`, as in the installed version. The new
release removes its own three war-goal callers. Within SB runtime source, the
two callers are the [Swazi conquest replacement](../../common/war_goal_types/zz_sb_swazi_conquest_override.txt)
and [Zulu annexation handoff](../../common/war_goal_types/zz_sb_zululand_annex_handoff.txt).

Recommend retiring that obsolete CMF override layer and the no-op calls from
SB's rebased copies. Preserve the Swazi restriction, the British–Zulu character
handoff and current native infamy/enforcement behaviour. This concerns the
examined Vanilla + CMF + SB stack; it does not certify behaviour of an additional
mod that replaces the placeholder trigger.

Keeping the hook would preserve an extension point, but in the examined stack it
adds no restriction or outcome. Removing it must not remove the independent SB
conditions/effects around it. The assent-only story and claim goals remain a
separate contract and should not acquire timer mirrors as part of this cleanup.
