## Complete upstream delta and disposition

The verified 1.67.1 → 1.67.2 release comparison changes six files, with no file
additions or removals:

| Upstream surface | Disposition |
| --- | --- |
| Metadata | Adopt version 1.67.2; game support remains `1.15.*` |
| Progress-bar effects | Adopt anonymous tagged containers, the cache and saved-scope wrapper unchanged |
| Progress-bar triggers | Adopt the new lookup and trigger wrapper; remove only `debug_log_details = true` |
| Demonstration journal | Adopt the release; remove only the empty wrapper call that lacks its required `effect` argument |
| Demonstration buttons | Adopt the wrapper-based calls unchanged |
| Progress-bar error localisation | Inherit upstream's container-to-scope diagnostic wording unchanged |

The exact removed call is the empty `run_in_com_progress_bar_scope` example in
`common/journal_entries/com_progress_in_style.txt`. Its preceding styling setup,
weekly pulse and outcome remain byte-identical to 1.67.2. The trigger correction
removes one diagnostic directive; it retains every lookup, cache, tag, saved scope
and conditional in `common/scripted_triggers/com_progress_bar_triggers.txt`.

The other two payloads, seven ideology-category helpers and native dynamic-bar
fallback rendering, are byte-identical to r1. All eight Vanilla contracts and
the exact GUI allowlist remain unchanged. All eight CMF definitions copied by
SB retain their complete source/object hashes; only their active dependency
labels change. Existing movement eligibility, scores, ordered effects and
performance guards retain their regression coverage.

SB has no callers of the changed container-backed styling helpers. Bechuanaland
and Imperial Confederation use the renderer with native bars; the Prerogative
marker uses static templates. No new helper adoption or gameplay migration is
required. This source finding does not establish rendered behaviour in the engine.
