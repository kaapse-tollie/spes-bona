## Cause and exact correspondence

The pinned native graph has no generated harbour on native impassable land.
Combining that same graph with SB's authored impassable mask produces exactly
15: seven in Namaqualand and eight in Hereroland. Twelve connect to Benguela
Coast and three to Cape of Good Hope, matching both coastal-graphics counts.

The engine's [docking branch](evidence/1_15_0_launch_retest_2026_11_05/docking_branch_arm64.txt)
looks up candidate land nodes in the harbour's province and emits the logged
message when none exists. SB's impassable provinces have no land destination to
serve these inherited landing points. This is distinct from a missing building
port or a rejected spline anchor.

The [record-by-record evidence](evidence/1_15_0_launch_retest_2026_11_05/harbour_derivation.json)
maps all 15 logged node IDs to province IDs and sea neighbours. In this run, 469
accepted naval spline anchors precede these generated records, giving
`runtime ID = 469 + native graph index`. These records precede the graph's
separately handled spline-derived entries; this is not a universal index offset.
The previous log's rejected anchor explains its one-lower IDs.

## Applied correction and preservation

[SB's naval graph](../../common/travel_network/naval_network.txt) is derived from
the exact native 1.15 graph by removing only those 15 harbour leaves and their
15 incident sea connections. Each removed node has degree one. No surviving
route is rerouted: node bodies remain exact and connection endpoint identities
and order survive index remapping. Counts change from **11,010 / 11,091** nodes /
connections to **10,995 / 11,076**.

This introduces a documented exact-path graph override, required because the
native cached graph does not reflect SB's impassable coastline. It supersedes the
earlier assumption that SB could retain this file wholly from Vanilla. Its
upstream and mod hashes are registered in the override inventory, with the mod
hash also pinned by map validation. Future game or impassable-mask changes require
rebuilding and reviewing this derivative.

Reproduce it with:

```sh
python3 -B tools/check_naval_network.py --write-network
```

Without that flag the [checker](../../tools/check_naval_network.py) is read-only:
it verifies the upstream hash and exact derived output. The generator refuses to
remove a harbour used as a through route or one lacking a single sea neighbour.
It does not change the installed game, land passability, province membership,
resource values, port locators or splines. All 1,136 starting repository files
were preserved separately under the retest's `before/` directory.
