# SB 1.15.0 implementation plan

Approved by DP on 5 November 2026. This records the implementation request;
results belong in the [implementation report](1_15_0_implementation.md).
The [design record](1_15_0_rebase_design_2026_11_05.md) supplies the detailed
policy, with native once-only events now included in this port.

1. Preserve the complete current working tree and installed dependency; record
   independent pre-port validation failures. Pin game build 26453692, core
   manifest 7727600027425614094 and CMF 1.67.1.
2. Stage CMF 1.67.1, create reproducible sb-1.15.0-r1 from demonstrated residual
   incompatibilities, retire obsolete territorial/cultural patch payloads and
   install through verified staging/rollback. Preserve SB's Swazi and British–Zulu
   hooks in current native war-goal bodies.
3. Apply the exact SB province-pixel delta to the current raster. Reconstruct
   other map inputs with explicit provenance. Restore upstream world/history
   changes; adopt native copper, remove Northern Cape's eight copper-proxy lead
   levels and carry native/custom-parent cold bounds. Preserve genuine lead and
   the provisional Namaqualand allowance. Do not certify unresolved map changes.
4. Migrate all 27 JEs, including shared/persistent/disabled entries, to outcomes.
   Port four obsolete bar styles without changing arithmetic or CMF indices.
   Rebase remaining overrides, DNA and syntax-only localisation requirements.
5. Audit all 321 event definitions. Migrate the six approved per-country
   occurrence-only events, retaining their gameplay effects and other guards.
   Preserve shared outcomes, repeatable episodes, retries and resource receipts.
   Any additional adoption requires the same demonstrated equivalence.
6. Update target metadata, current inventories, synchronisation checks and
   regression expectations only after semantic review. Run appropriate static
   and full regression checks. Keep engine timing, rendering and performance
   claims separate from source-model checks.
7. Deliver an uncommitted working tree, source evidence and DP's fresh-campaign
   runtime checklist. All DLC are required; no old-save migration, game launch,
   publication or release-version bump. Record every remaining engine gate.

Acceptance covers dependency integrity/repeatability/rollback; map delta and
parent-resource conservation; positive and deliberately broken naval controls;
JE terminal effects and cleanup; once-only duplicate, held-popup, failed-delivery,
cancellation, country-identity and save/load cases; affected cross-country,
political, succession, recruitment and relief regressions. Native lifecycle
behaviour is verified by DP, not a fixture that assumes the engine's timing.

All other resource, glossary, JE-extension, character, music and loading-screen
tasks retain their agreed destinations in the [open register](../audit_issues_open.md).
