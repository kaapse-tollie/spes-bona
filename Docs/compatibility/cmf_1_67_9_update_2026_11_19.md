## Compatibility decisions

| Area | Effective behaviour |
| --- | --- |
| Retained SB payloads | The seven ideology-category triggers preserve Vanilla’s character and interest-group checks plus the CMF extensions. The progress-bar scope trigger omits unconditional debug logging. Both payloads match SB’s r1 bytes. |
| Political movements | CMF supplies the six 1.15.1 secession opt-ins across four files. Of 24 CMF definitions copied by SB, 23 bodies match the preceding installation exactly. Only indentation changed in the cultural-minority body. The cultural-movement file has three inventory entries. The gameplay scripts require no edits. |
| Progress bars and demo | CMF supplies the full and compact dynamic renderers, including the periodic breakdown tooltip. Its demo passes the required empty `effect` parameter. These two former SB payloads are retired. |
| Shared outliner | Ordinary pinned journals, situations and organisations now instantiate `com_outliner_entry`. The SB definition matches this type except for four points of spacing between scripted bars. Each CMF container owns its visibility filter. Objective rows follow the native route. |
| Other upstream changes | The updated regency events supply opt-in country flags. SB has no callers of those blockers or of the removed dictionary and struct effects. The event-window, mod-detection and diagnostic GUI changes come from the release. |

CMF’s standalone `com_journal_outliner_progress_bars` helper selects its green
mini-bar with `IsDefaultBad`. No CMF or SB outliner instantiates that helper.
The shared row inherits Vanilla’s `journal_entry_scripted_progress_bars`,
which selects green with `IsDefaultGreen`. ## Verification

The original installation passed 80 focused tests. The new shared-row
regression reproduced the old situation-only definition before the port.
The staged candidate passed 36 tests, all fourteen native contracts and the
override comparison covering 41 exact paths and 151 keyed overrides.
The post-install offline `sync_cmf.py --check` passed.

The first full run discovered 1,170 unit tests and nine conditional skips.
Its sole failure was an old date expectation for the three cultural-movement
inventory entries. The regression now requires their 19 November review date.
The focused retest and complete rerun passed.

The final validator recorded **15 passes, two existing warnings and zero failures**.
The warnings cover five deferred release gates and Tiger 1.19.0’s incomplete
1.15 schema. The installed tree differs from the official archive in exactly
the two manifest payloads. [Full validator output](evidence/cmf_1_67_9_validation_2026_11_19.txt)
